 JobTrack - Job Application Management System

Project Description

JobTrack is a web-based Job Application Management System developed for the IMS566 course. The system helps users manage and track their job applications in one place.

Users can record job applications, monitor application status, manage company information, and view application progress through the dashboard.

 Main Features

- User Login Authentication
- Dashboard with application summary
- Application tracking
- Add, edit, and delete job applications
- Search, filter, and sort applications
- Company information management
- Company application insights
- Application status tracking
- Data visualisation using charts
- Responsive design for different screen sizes

 Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap 5.3.3
- Bootstrap Icons
- Chart.js
- Local Storage
- Session Storage

 Data Management

JobTrack uses browser Local Storage to store job application data during the demo. Session Storage is used to maintain the user's login session.

 Responsive Design

The system is designed to work on desktop, tablet, and mobile screen sizes.
